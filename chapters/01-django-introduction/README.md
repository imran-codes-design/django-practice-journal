# Chapter 01 — Django Introduction

## Overview

This chapter introduces Django, a high-level Python web framework used to build secure, scalable, and maintainable web applications.

It covers Django fundamentals, its architecture, and the request-response lifecycle.

## Learning Objectives

- Understand what Django is and why it is used.
- Identify the main features of Django.
- Understand the MVT architecture.
- Explain the responsibilities of Models, Views, and Templates.
- Understand Django's request-response lifecycle.

## Key Takeaways

- Django is a Python-based web framework.
- Django follows the Model-View-Template architectural pattern.
- Views process requests and coordinate application logic.
- Models manage application data.
- Templates generate the presentation layer.
- Django processes requests through its request-handling system and returns HTTP responses.
