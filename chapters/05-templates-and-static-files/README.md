# Chapter 05 — Django Templates and Static Files

## Overview
This chapter covers rendering dynamic HTML with Django's template engine and serving frontend assets such as CSS, JavaScript, and images. Documentation is separate from executable Django source code.

## Learning Objectives
- Explain the role of templates in Django's request-response cycle.
- Pass context data from views to templates.
- Use template variables, tags, and filters.
- Reuse layouts through template inheritance.
- Configure template directories and understand template discovery.
- Organize and load application-level static files.
- Integrate Bootstrap into Django templates.

## Practical Workflow
1. Review existing templates in the Django applications.
2. Pass context data from a view to a template.
3. Practise variables, tags, and filters.
4. Build a reusable base template and child templates.
5. Inspect template discovery settings and directory conventions.
6. Add CSS, JavaScript, and image assets under an app's static directory.
7. Integrate Bootstrap and test the rendered pages.
